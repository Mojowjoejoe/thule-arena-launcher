# Thule Arena default keybindings

[Download the keymap](ThuleArena-KeyMaps.ini). Captured from Mojow's saved EQPVP configuration on September 21, 2026.

The corrected default keeps target-NPC and target-player bindings and disables both NPC and player cycling overrides that previously shared their keys. Movement and the other saved overrides are unchanged.

This is a preset, not an automatic launcher patch. To apply it, close EverQuest, back up your `eqclient.ini`, then replace only its `[KeyMaps]` section with this file's section. Preserve all other sections, including display and audio settings. Use your separate Thule Arena client copy. Actions absent from this preset retain the client's built-in defaults.

The launcher continues to preserve existing players' personal keybindings.
